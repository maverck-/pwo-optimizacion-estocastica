  formato paper.

  distribuido entre ambos integrantes.

  previamente. No es la referencia actual para preparar la presentación.

La referencia actual del contenido está en:

- `docs/presentacion/presentacion-avance.md`
- `docs/presentacion/guion-presentacion.md`

Antes de enviar:

1. revisar el informe y la presentación entre ambos autores;
2. exportar el informe al formato final solicitado;
3. construir la presentación definitiva a partir de la guía;
4. abrir los archivos finales para comprobar su integridad.

Las fuentes principales se mantienen en `docs/`. Si se modifica el informe o el
guion, sus copias de esta carpeta deben volver a sincronizarse.
